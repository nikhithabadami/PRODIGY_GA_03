# PRODIGY_GA_03

## Task 3: Text Generation using Markov Chains

### Objective
Develop a text generation program using Markov Chains to generate coherent text from a given dataset.

---

## Project Description

This project demonstrates how Markov Chains can be used for text generation. The program learns word transition patterns from a sample dataset and generates new sentences that resemble the style of the original text.

---

## Technologies Used

- Python
- Markovify
